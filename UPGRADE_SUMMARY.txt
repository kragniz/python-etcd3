QUICK START

For Application Developers:

  1. Upgrade Python:
     $ python3 --version  # Must be 3.9+

  2. Install updated package:
     $ pip install --upgrade etcd3

  3. Test your application:
     $ pytest tests/

For Library Maintainers:

  1. Install dependencies:
     $ pip install -r requirements/base.txt
     $ pip install -r requirements/test.txt

  2. Run tests:
     $ PYTHON_ETCD_HTTP_URL=http://localhost:12379 pytest tests/

  3. Regenerate protobuf stubs (if needed):
     $ python -m grpc.tools.protoc -Ietcd3/proto \
         --python_out=etcd3/etcdrpc/ \
         --grpc_python_out=etcd3/etcdrpc/ \
         etcd3/proto/*.proto
